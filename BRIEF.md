*Version 9 · 2026-10-27 (round 9: taste pass, ten fixes from a design-taste critique; round 8: liquid drips, a new viper that watches the cursor, every work in the studio's post style, Procreate on the desk screen) · method: `immersive-scroll-film-site` (see `LAPVISOR_skill-and-blueprint.md`).
Read this before touching `site/`. Conflict rule: this file beats older notes; the code beats this file only for owner-approved changes.*

## 0. Golden rule

**The work is the film.** Every moving thing on the site is either his real tattoo work or a code-drawn effect taken from his own visual world (neon red and blue, cracked white sculpture, gold kintsugi, glitch posters). **AI only where the owner asked for it, and said so on the page**: since round 6 the floating designs (hero, wall, "Solo il disegno" in the lightbox) are AI redraws of his real tattoos, each made from the original photo with an instruction to copy it 1:1; the footer discloses it. Every photo, every archive work and every motion stays real or code-drawn, and no design is invented. Caution: in March 2026 he posted a reel arguing that using AI is wrong for a tattoo artist — see OPEN 8.

## 4. Engineering rules kept from the skill

**Mobile pass (round 8, owner: "the website on mobile needs a lot of optimisation, the scrolling and changing of page frames stutters")** — keep these: pinned acts are CSS `position: sticky` stages in a section one screen plus the scroll length tall (`stickyLength()` in main.js; the wall's length is measured before each refresh), never GSAP `pin` (on phones the finger scroll runs on the compositor and a JS pin switches to fixed a frame late: the jump at each act's edges) · heights in `svh`/`vh`, never `dvh` (the address bar resized the 604dvh hero, shifting every act after it) · nothing writes a custom property on `:root` per frame (`--ca` lives on the badge, written only on change: on :root it restyled the whole page every frame) · per-frame loops write styles only when a value changes and read no layout (the rail caches the page length) · tunnel textures decode off the main thread and reach the GPU one per frame on phones · phones skip: the animated blend-mode grain, the nav's backdrop blur, the Art Wall's 130 drop-shadow filters, the badge's chroma filter, falling drips, the live desk screen (the photo keeps its owl sketch), MSAA on the owl · the idle ink canvas is hidden · Studio Space ambient: softened in a tiny canvas, no CSS blur. Measure with `node scripts/perf-mobile.mjs` (phone, CPU ×4, steady scroll, per act): before the pass mean frame 33 ms, p95 69 ms, 23 % frames > 25 ms, worst 965 ms, style recalc 7.0 s per run; after it mean 8 ms, p95 14 ms, 0 %, worst 28–42 ms, 1.5 s (headless numbers, two runs each).

Shared state above trigger wiring · no JS pins (sticky stages, see above) · Lenis owns scroll (`window.__lenis` for QA) · ScrollTrigger refresh on width change only · DPR ≤ 2 · `100svh` (never `dvh`) + safe-area insets · one pulsing CTA at a time · swipe = `|dx|>34 && |dx|>1.4|dy|` · QA with the headless scroll ladder at 1280×720 and 390×844, 0 exceptions, 0 horizontal overflow.
